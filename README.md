# raman-machine-learning

 Raman Spectroscopy Data Analysis

This project presents Python-based analysis of Raman spectroscopy data.

## Methods
- PCA-lda
- plsda
- pca-svm
- Machine learning
- Data visualization

## Technologies
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Project Structure
- `notebooks/`: Jupyter notebooks
- `src/`: Python scripts
- `results/`: generated figures
